# Claude Codeでの実行

- このSkillへの明示的な依頼は、`--auto`で選んだ人格を執筆に呼ぶことへの依頼も含む。一般的な開発作業で勝手に人格を起動しない。
- Skill呼び出しに渡された引数とユーザーの依頼を読む。Claude Codeの`$ARGUMENTS`が展開される場合はその内容も使う。
- 登録された16-mindsの人格subagent（通常`16-minds:<type>`）を確認し、使用版のネイティブAgentツール（旧版ではTask）で1回呼ぶ。ツール名や登録名は利用中の環境に従い、存在しないツールを作らない。
- subagentに渡すもの: 確定したtype、共通仕様の執筆契約全文、目的・相手・媒体・形式・目安長さ、守る事実・意図・制約、ユーザーの材料。元文章は資料と分かる区切りで囲む。
- subagentには元のチャット文脈が自動で渡ると仮定しない。ファイルの編集、Web検索、追加のsubagent起動は執筆の要件にしない。
- 人格が登録されていない場合は、pluginの有効化・再読み込みと`/agents`での確認を案内し、執筆を中断する。人格本文を主Agentが読むだけの処理を、subagent呼び出し成功として扱わない。
